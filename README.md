## ⚡ Pure CSS & Zero-JS Engineering Feats
All dynamic interactive behaviors are engineered entirely using modern HTML5 semantic elements and CSS3 pseudo-classes:
* **Pure CSS Theme Switcher:** Light/Dark mode switcher built using `:root:has(#theme-toggle:checked)` and CSS custom design tokens without a single line of JavaScript.
* **Pure CSS Mobile Navigation Drawer:** Fully accessible slide-down mobile navigation powered by hidden checkbox state toggles.
* **Pure CSS Modal Dialogs:** Interactive certificate preview popups engineered with the CSS `:target` pseudo-class.
* **Native Disclosure Accordions:** Dynamic expansion of internship history and certifications built with native HTML5 `<details>` and `<summary>`.
* **Semiconductor Grid Aesthetics:** Custom wafer substrate grid patterns, chip-bezel cards, and micro-metric hardware telemetry cards.
